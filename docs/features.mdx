HashPilot provides **32 MCP tools with 130+ operations** covering the complete Hedera development workflow. Here's an overview of what you can do.

## Account Management

Manage Hedera accounts with natural language:

- **Create accounts** with an ECDSA key pair and a configurable initial HBAR balance
- **Query balances** for HBAR and all associated tokens (free Mirror Node query, no operator needed)
- **Get account info** including EVM address, key type, memo, expiration and staking (free)
- **Transfer HBAR** between accounts
- **Inspect transaction history** through the Mirror Node (free)

```
"Create a new account with 50 HBAR"
"Check the balance of 0.0.12345"
"Transfer 10 HBAR to 0.0.67890"
```

## Token Operations (HTS)

Fungible token lifecycle through the Hedera Token Service:

| Operation | Description |
|-----------|-------------|
| **create** | Create a fungible token with custom fees (fixed, fractional, royalty) and admin, supply, freeze, KYC, wipe and pause keys |
| **associate** | Associate a token with an account |
| **transfer** | Transfer tokens between accounts |
| **mint** | Mint additional tokens |
| **burn** | Burn tokens from the treasury |
| **freeze/unfreeze** | Control an account's ability to transfer |
| **kyc_grant/kyc_revoke** | Manage KYC compliance |
| **pause/unpause** | Halt or resume all token operations |
| **wipe** | Remove tokens from an account |

```
"Create a fungible token called MyToken with symbol MTK and a supply key"
"Associate token 0.0.12345 with account 0.0.67890"
"Transfer 100 MTK tokens to 0.0.67890"
```

## Consensus Service (HCS)

Hedera Consensus Service for ordered messaging:

- **Create topics**, public or private (submit key), with optional admin key
- **Submit messages** with automatic chunking for payloads over 1 KB
- **Query messages** by sequence number from the Mirror Node (free)
- **Read topic info** from the Mirror Node (free)
- **Subscribe** to real-time message streams

```
"Create a private HCS topic for audit logs"
"Submit message 'Transaction approved' to topic 0.0.12345"
"Get the last 10 messages from topic 0.0.12345"
```

## Smart Contracts

Deploy and interact with Solidity contracts:

### Hardhat Integration
- Scaffold a project with a Hedera-ready config and a sample contract
- Compile contracts
- Run tests with Mocha/Chai
- Deploy with a script or Hardhat Ignition, signed with your operator key
- Call (free) and execute contract functions

### Foundry Integration
- Scaffold a project (runs `git init` and installs `forge-std`)
- Build with forge, run fuzz tests with gas reports
- Deploy with `forge create` or a broadcast script
- Call (free) and send transactions with cast
- Start and stop a local Anvil node, optionally forking a network

### Verification
- Verify on Sourcify, which HashScan uses to display source code (mainnet and testnet)
- Keep a deployment history and export it as JSON, CSV or Markdown

### JSON-RPC Operations
- Any method the JSON-RPC relay supports (`eth_*`, `web3_*`, `net_*`, `debug_*`)
- `eth_call` for read operations (free)
- Deploy and execute contracts with the operator key
- Use a production relay via `JSON_RPC_RELAY_URL`

```
"Deploy my Greeter.sol contract to testnet"
"Call the greet function on contract 0x..."
"Verify my contract on testnet"
```

## Stablecoin Studio

Enterprise-grade stablecoin management:

- **Create** compliant stablecoins with role-based controls
- **Cash-in/Burn** with allowance management
- **Freeze/Unfreeze** individual accounts
- **KYC management** for compliance
- **Pause/Unpause** for emergency controls
- **Role management** (CASHIN, BURN, WIPE, RESCUE, PAUSE, FREEZE, KYC, DELETE)
- **Proof-of-Reserve** support

```
"Create a USD-backed stablecoin with KYC requirements"
"Grant CASHIN role to account 0.0.12345"
"Check stablecoin balance for account 0.0.67890"
```

<Note>
Built-in Stablecoin Studio contracts exist for testnet. Mainnet and previewnet need `STABLECOIN_FACTORY_ADDRESS` and `STABLECOIN_RESOLVER_ADDRESS` in your configuration.
</Note>

## Documentation and Code Generation

AI-powered knowledge base over a pre-indexed ChromaDB collection of Hedera documentation:

### docs_search
Semantic search with filters for content type, language and code presence:
```
"Search for token creation examples in JavaScript"
```

### docs_ask
Ask questions and get cited answers at your expertise level:
```
"How do scheduled transactions work on Hedera?"
```

### docs_get_example
Find working, annotated code examples:
```
"Show me an example of creating an NFT in Java"
```

### code_generate
Generate SDK code from descriptions:
```
"Generate TypeScript code to create a fungible token with 2 decimals"
```

**Indexed Sources:**
- Official Hedera Documentation
- SDK References (JavaScript, Java, Go, Rust, Python)
- Hedera Improvement Proposals (HIPs)
- Tutorials and Examples
- Smart Contract Patterns
- Network fees, exchange rates and staking data

<Note>
These four tools require an OpenAI API key in your MCP settings. They query HashPilot's hosted index by default; see [Self-hosting](/self-hosting) to run your own.
</Note>

## Development Tools

### Address Book
Save and manage multiple accounts:
- Add account references
- Import accounts with private keys for signing
- Organize with aliases and nicknames

### State Management
- Backup server state (private keys excluded by default)
- Restore from backups, replacing or merging
- Export state as JSON

All persisted data lives in `~/.hedera-mcp` or the directory named by `HASHPILOT_DATA_DIR`.

### Error Explanation
Get help understanding Hedera errors, offline and free:
```
"Explain error INSUFFICIENT_PAYER_BALANCE"
```

### Health Check
`health_check` reports version, tool count, network and operator. With `verbose` it also probes the Mirror Node and the docs index and shows the JSON-RPC relay in use.

### Network Switching
Switch between networks seamlessly:
- mainnet
- testnet
- previewnet
- local (for development)

## Operator Key Handling

HashPilot accepts DER-encoded and raw hex private keys. Raw hex keys are assumed ECDSA unless `HEDERA_OPERATOR_KEY_TYPE=ed25519` is set. On startup the key is checked against the account's key on the Mirror Node, and the server refuses to run with a mismatched key.

## Auto-Key Resolution

HashPilot automatically uses your configured operator account for all operations. No need to manually specify private keys for every deployment or transaction.

**Resolution order:**
1. Explicitly provided key in the request
2. MCP operator account (default)
