Every tool name, operation and parameter on this page is taken from the server's tool schema; `health_check` reports the live tool count.

## Health (1 tool)

### health_check

Check server health and status. **FREE.**

- **verbose** (boolean): Also probe external services

Returns `status`, `version`, `toolCount`, `network`, `operatorConfigured` and `operatorId`. With `verbose: true` it adds:

- `services.mirrorNode`: URL and reachability
- `services.jsonRpcRelay`: URL in use (your `JSON_RPC_RELAY_URL` or the Hashio default)
- `services.chromadb`: URL, reachability of the docs index, and `ragEnabled` (true when `OPENAI_API_KEY` is set)
- `system`: Node.js version, platform and architecture

## Account Management (4 tools)

### account_create

Create a new Hedera account with an auto-generated **ECDSA** key pair, funded from the operator account.

- **initialBalance** (number): Initial HBAR (default: 1)
- **memo** (string): Account memo (max 100 chars)
- **publicKey** (string): Use an existing public key instead of generating one

Returns the new account ID, its private and public key, and the transaction ID. Costs the network fee plus the initial balance.

### account_balance

Query HBAR and token balances for any account. **FREE via Mirror Node, no operator needed.**

- **accountId** (string, required): Account ID (`0.0.xxxxx`)

Token balances are returned in the token's smallest unit; apply the token's decimals yourself.

### account_info

Get account details: balance, EVM address, public key and key type, memo, auto-renew period, expiration and staking info. **FREE via Mirror Node, no operator needed.**

- **accountId** (string, required): Account ID

### transfer_hbar

Transfer HBAR between accounts. Signed by the operator, so the operator must be the source or have signing authority over it.

- **from** (string, required): Source account ID
- **to** (string, required): Destination account ID
- **amount** (number, required): HBAR amount

## Network Management (2 tools)

### network_info

Return the active network, its Mirror Node URL and its JSON-RPC relay endpoint. **FREE.** No parameters.

### network_switch

Switch the active network. The choice is saved in the data directory and survives restarts.

- **network** (string, required): `mainnet`, `testnet`, `previewnet` or `local`

<Note>
  `JSON_RPC_RELAY_URL` and `MIRROR_NODE_URL` only apply to the network named in `HEDERA_NETWORK`.
  After switching to another network HashPilot uses the public Hedera endpoints for it.
</Note>

## Token Operations - HTS (1 tool, 12 operations)

### token_manage

Unified fungible token management. Amounts and supplies are in the token's smallest unit (with `decimals: 2`, an amount of `100` is `1.00`).

| Operation    | Description                                                                  | Key Parameters                                                                                                                                         |
| ------------ | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `create`     | Create a fungible token                                                      | `name`, `symbol`, `decimals` (default 0), `initialSupply`, `memo`, `adminKey`, `supplyKey`, `freezeKey`, `kycKey`, `wipeKey`, `pauseKey`, `customFees` |
| `associate`  | Associate a token with an account (required before it can receive the token) | `tokenId`, `accountId`, `privateKey` (the account's key when it is not the operator)                                                                   |
| `transfer`   | Transfer tokens                                                              | `tokenId`, `from`, `to`, `amount`, `senderPrivateKey` (when `from` is not the operator)                                                                |
| `mint`       | Mint additional supply (needs supply key)                                    | `tokenId`, `amount`                                                                                                                                    |
| `burn`       | Burn supply from the treasury (needs supply key)                             | `tokenId`, `amount`                                                                                                                                    |
| `freeze`     | Freeze an account for the token (needs freeze key)                           | `tokenId`, `accountId`                                                                                                                                 |
| `unfreeze`   | Unfreeze an account                                                          | `tokenId`, `accountId`                                                                                                                                 |
| `kyc_grant`  | Grant KYC to an account (needs KYC key)                                      | `tokenId`, `accountId`                                                                                                                                 |
| `kyc_revoke` | Revoke KYC                                                                   | `tokenId`, `accountId`                                                                                                                                 |
| `pause`      | Pause all operations on the token (needs pause key)                          | `tokenId`                                                                                                                                              |
| `unpause`    | Resume operations                                                            | `tokenId`                                                                                                                                              |
| `wipe`       | Remove tokens from an account (needs wipe key)                               | `tokenId`, `accountId`, `amount`                                                                                                                       |

The key flags (`adminKey`, `supplyKey`, `freezeKey`, `kycKey`, `wipeKey`, `pauseKey`) are booleans. When enabled, the operator key is set as that key, and the operator account is the treasury.

**Custom fees** (`customFees`, array, `create` only): each entry has `feeType` (`fixed`, `fractional` or `royalty`) and `feeCollectorAccountId`, plus `amount` (fixed amount, or the numerator for fractional fees), `denominator`, `min`, `max`, `denominatingTokenId` (fixed fees paid in another token) and `fallbackFee` (royalty fees).

## JSON-RPC Operations (4 tools)

These tools talk to the JSON-RPC relay for the active network (Hashio by default, or your `JSON_RPC_RELAY_URL`). Chain IDs are 295 (mainnet), 296 (testnet), 297 (previewnet) and 298 (local).

### rpc_call

Execute any method the relay supports (`eth_*`, `web3_*`, `net_*`, `debug_*`). Read methods are **FREE**.

- **method** (string, required): e.g. `eth_blockNumber`, `eth_getBalance`, `eth_call`, `eth_getLogs`, `eth_sendRawTransaction`
- **params** (array): Method parameters
- **network** (string): `mainnet`, `testnet`, `previewnet` or `local` (default: active network)

Results are decoded to human-readable values where possible (chain IDs, balances, block numbers).

### rpc_call_contract

Call a view or pure function via `eth_call`. **FREE, no gas.**

- **contractAddress** (string, required): `0x` address
- **abi** (array, required): Contract ABI
- **functionName** (string, required): Function to call
- **args** (array): Function arguments

### rpc_deploy_contract

Deploy bytecode via the relay. Handles constructor encoding, gas estimation and receipt polling.

- **bytecode** (string, required): Contract bytecode (`0x...`)
- **abi** (array): Contract ABI (needed to encode constructor arguments)
- **constructorArgs** (array): Constructor arguments
- **privateKey** (string): Deployer key (optional, defaults to the operator key)

### rpc_execute_contract

Send a state-changing transaction via `eth_sendRawTransaction`.

- **contractAddress** (string, required): Contract address
- **abi** (array, required): Contract ABI
- **functionName** (string, required): Function name
- **args** (array): Function arguments
- **value** (string): Value to send, in wei
- **privateKey** (string): Sender key (optional, defaults to the operator key)

<Note>
  EVM operations sign with an ECDSA key. If your operator account uses an ED25519 key, pass an ECDSA
  `privateKey` for these tools, or use the native SDK tools instead.
</Note>

## Documentation and Code Generation (4 tools)

With `OPENAI_API_KEY` set, all four query the ChromaDB index at `CHROMA_URL` (HashPilot's hosted index by default), which covers docs.hedera.com, HIPs, HCS standards, protobuf definitions, SDK examples in five languages and the Solo, CLI, Mirror Node, Agent Kit and smart-contract repositories. They cost OpenAI tokens, never HBAR.

Without a key, or when the index cannot be reached, they answer from Hedera's official documentation search at `docs.hedera.com/mcp` instead: free and keyless, but limited to docs.hedera.com and hips.hedera.com. `docs_ask` then returns the relevant documentation rather than a written answer, and `code_generate` returns the documentation to write the code from. Every fallback response says so and why.

### docs_search

Semantic search across the indexed Hedera documentation, SDK references, tutorials and HIPs.

- **query** (string, required): Natural-language search query
- **limit** (number): Max results (default 5, max 20)
- **contentType** (string): `tutorial`, `api`, `concept`, `example`, `guide` or `reference`
- **language** (string): `javascript`, `typescript`, `java`, `python`, `go` or `solidity`
- **hasCode** (boolean): Only return chunks that contain code

### docs_ask

Answer a question with retrieval-augmented generation and source citations.

- **question** (string, required): Your question
- **expertiseLevel** (string): `beginner`, `intermediate` or `advanced`
- **includeCodeExamples** (boolean): Include code in the answer
- **language** (string): Preferred language for examples (same list as `docs_search`)

### docs_get_example

Find working code examples with explanations and source references.

- **description** (string, required): What the code should do
- **language** (string): `javascript`, `typescript`, `java`, `python`, `go`, `rust` or `solidity`
- **complexity** (string): `simple`, `intermediate` or `advanced`
- **limit** (number): Max examples (default 5)

### code_generate

Generate runnable SDK code from a description, grounded in indexed examples.

- **description** (string, required): What to generate
- **language** (string): `javascript` (default), `typescript`, `java`, `python`, `go` or `solidity`
- **style** (string): `minimal`, `complete` (default) or `production`
- **includeImports** (boolean): Include imports (default true)
- **includeErrorHandling** (boolean): Include try/catch (default true)

## Smart Contract Deployment (4 tools)

### deploy_contract

Unified deployment. Detects a Hardhat or Foundry project in the current directory, or falls back to direct RPC deployment, and records the result in the deployment history.

- **contractName** (string, required): Contract name
- **network** (string, required): `mainnet`, `testnet` or `previewnet`
- **constructorArgs** (array): Constructor arguments
- **framework** (string): `hardhat`, `foundry` or `direct` (auto-detected if omitted)
- **verify** (boolean): Attempt verification after deployment

### verify_contract

Submit source code for verification. HashScan reads verification status from [Sourcify](https://sourcify.dev), which supports Hedera mainnet (chain 295) and testnet (chain 296) only.

- **address** (string, required): Contract address (`0x...`)
- **network** (string, required): `mainnet` or `testnet` (`previewnet` is accepted by the schema but cannot be verified)
- **contractName** (string, required): Contract name
- **filePath** (string, required): Path to the `.sol` file or a directory of `.sol` files

Returns the match status and the HashScan URL.

### deployment_history

List past deployments. **FREE.**

- **network** (string): `mainnet`, `testnet` or `previewnet`
- **contractName** (string): Filter by name
- **limit** (number): Max results (default 20)
- **exportFormat** (string): `json`, `csv` or `markdown`

History is stored in `deployments.json` in the data directory.

### mirror_query_account

Query an account from the Mirror Node REST API, optionally with recent transactions. **FREE.**

- **accountId** (string, required): Account ID
- **includeTransactions** (boolean): Include recent transactions
- **transactionLimit** (number): Transaction count (default 20)

### mirror_query

Every other read-only Mirror Node query, selected by **resource**. **FREE**, no operator needed. Each resource takes the parameters shown; the tool reports any required one that is missing.

| Resource                                              | Returns                                                                                                    | Required                                                   |
| ----------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| `account`, `accounts`                                 | Account details; list of accounts                                                                          | `accountId` for `account`                                  |
| `account_tokens`, `account_nfts`, `account_rewards`   | Token relationships, owned NFTs, staking rewards                                                           | `accountId`                                                |
| `balances`                                            | Balance snapshots                                                                                          | -                                                          |
| `transactions`                                        | Recent transactions, filterable by `accountId`, `transactionType`, `result`, `timestamp`                   | -                                                          |
| `transaction`                                         | One transaction: status, fee, transfers                                                                    | `transactionId`                                            |
| `token`, `tokens`                                     | Token info (supply, keys, fees, treasury); list of tokens                                                  | `tokenId` for `token`                                      |
| `token_balances`                                      | Holders of a token                                                                                         | `tokenId`                                                  |
| `nfts`, `nft`, `nft_history`                          | NFTs of a collection; one NFT; its transfer history                                                        | `tokenId`, plus `serialNumber` for `nft` and `nft_history` |
| `topic`, `topic_messages`                             | Topic info; its messages                                                                                   | `topicId`                                                  |
| `contracts`, `contract`                               | List of contracts; one contract with bytecode                                                              | `contractId` for `contract`                                |
| `contract_state`, `contract_results`, `contract_logs` | Storage slots, execution results, event logs                                                               | `contractId`                                               |
| `contract_call`                                       | Free read-only call or gas estimate (`eth_call` simulation)                                                | `to`, `data`                                               |

| `schedules`, `schedule`                               | Scheduled transactions; one with its signatures                                                            | `scheduleId` for `schedule`                                |
| `network_info`                                        | Live fee-conversion exchange rate, fee schedule, supply                                                    | -                                                          |
| `network_nodes`, `network_stake`                      | Consensus nodes; staking parameters                                                                        | -                                                          |

### graphql

Query indexed Hedera Mirror Node data with GraphQL, through [Hgraph](https://hgraph.com). Hedera's public Mirror Nodes offer only REST; Hgraph serves the same data over GraphQL for mainnet and testnet. Needs `HGRAPH_API_KEY` (a free key is available at [app.hgraph.com](https://app.hgraph.com)); set `GRAPHQL_ENDPOINT` to use a different endpoint. **Read-only**: mutations and subscriptions are refused.

| Operation  | Description                                                                                                                         | Key Parameters                                                                    |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `schema`   | List queryable entities, or the fields and filter arguments of one                                                                  | `search`, `entity`, `refreshSchema`                                               |
| `generate` | Build a query for an entity from the schema, with filters passed as typed variables, and validate it; add `execute: true` to run it | `entity`, `fields`, `where`, `orderBy`, `limit` (default 10), `offset`, `execute` |
| `validate` | Check a hand-written query against the schema without running it; problems come back with line and column                           | `query`                                                                           |
| `execute`  | Run a read-only query                                                                                                               | `query`, `variables`                                                              |

Filters use Hasura syntax, for example `where: {"type": {"_eq": "NON_FUNGIBLE_UNIQUE"}}` and `orderBy: {"consensus_timestamp": "desc"}`. The schema is cached per network in the data directory for a day. Large results are trimmed to fit a response, with a note saying how many rows were left out. The free Hgraph plan allows one request per second.

## Stablecoin Studio (1 tool, 18 operations)

### stablecoin_manage

Compliant stablecoins through the [Hedera Stablecoin Studio](https://github.com/hashgraph/stablecoin-studio) SDK. Built-in factory and resolver contracts exist for **testnet only**; mainnet and previewnet need `STABLECOIN_FACTORY_ADDRESS` and `STABLECOIN_RESOLVER_ADDRESS` (and optionally `STABLECOIN_CONFIG_ID` / `STABLECOIN_CONFIG_VERSION`) in the environment.

| Operation                                   | Description                                             |
| ------------------------------------------- | ------------------------------------------------------- |
| `create`                                    | Create a stablecoin with role-based controls            |
| `info`                                      | Get stablecoin details (supply, treasury, pause status) |
| `balance`                                   | Check an account's balance                              |
| `cashin`                                    | Mint tokens to an account (CASHIN role)                 |
| `burn`                                      | Burn tokens from the treasury (BURN role)               |
| `wipe`                                      | Remove tokens from an account (WIPE role)               |
| `rescue`                                    | Rescue tokens from the proxy treasury (RESCUE role)     |
| `rescue_hbar`                               | Rescue HBAR from the proxy (RESCUE role)                |
| `freeze` / `unfreeze`                       | Control an account's ability to transfer (FREEZE role)  |
| `pause` / `unpause`                         | Halt or resume all operations (PAUSE role)              |
| `kyc_grant` / `kyc_revoke`                  | Manage KYC status (KYC role)                            |
| `role_grant` / `role_revoke` / `role_check` | Manage role assignments                                 |
| `delete`                                    | Permanently delete the stablecoin (DELETE role)         |

**Parameters:** `stablecoinId` (most operations), `targetAccount`, `amount` (string, for exact decimals), `role` (`CASHIN`, `BURN`, `WIPE`, `RESCUE`, `PAUSE`, `FREEZE`, `KYC`, `DELETE`), `network`.

**Create parameters:** `name`, `symbol`, `decimals` (default 6), `initialSupply`, `maxSupply`, `supplyType` (`INFINITE` or `FINITE`), `memo`, `freezeDefault`, role accounts (`cashInRoleAccount`, `burnRoleAccount`, `wipeRoleAccount`, `rescueRoleAccount`, `pauseRoleAccount`, `freezeRoleAccount`, `kycRoleAccount`, `deleteRoleAccount`; each defaults to the operator), `cashInAllowance`, `createReserve`, `reserveInitialAmount`, `reserveAddress`, `proxyAdminOwnerAccount`.

## Auto-Key Resolution

Transaction tools sign with the operator key unless told otherwise:

1. An explicit `privateKey` parameter (RPC, Hardhat `execute`, Foundry `create`/`script`/`send`)
2. The operator account from your MCP configuration

For Hardhat deployments the operator key is injected as the `<NETWORK>_PRIVATE_KEY` variable the generated config expects. Foundry tools fill in `rpcUrl` from the active network as well.
